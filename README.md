# Discord Voice Activity Tracker Bot

Профессиональный Discord-бот на Python для автоматического учета и анализа времени, проведенного пользователями в голосовых каналах сервера. 

## 🚀 Основной функционал
* **Логирование голосовой активности:** Бот фиксирует точное время входа и выхода пользователей из голосовых комнат.
* **Финальный подсчет сессий:** Алгоритм автоматически рассчитывает и сохраняет суммарное время каждого участника сразу после того, как все пользователи покидают голосовой канал.
* **Автономность 24/7:** Архитектура оптимизирована для непрерывной работы (uptime) на удаленном сервере (VPS/VDS).

## 🛠 Стек технологий
* **Язык:** Python 3.10+
* **Библиотека:** discord.py (или укажи disnake/nextcord, если использовал их)
* **Асинхронность:** asyncio / datetime (для точного расчета таймстемпов без блокировки потоков)

## 📦 Как запустить проект локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Укажите ваш токен Discord-бота в конфигурационном файле или коде.
4. Запустите скрипт:
   ```bash
   python botds.py
   ```
